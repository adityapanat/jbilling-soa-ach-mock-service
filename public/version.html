What this service offers

ACH return simulation

Returns a SnapPay-compatible failed transaction for registered IDs, including a configurable return code, description, amount, and transaction date.

Transaction registry

Register, search, sort, and page through test transactions in the browser, or manage them through the REST API.

Settlement fallback

Unregistered transaction IDs receive a successful GetTransaction response, allowing the settlement flow to skip them.

Local persistence

Registered scenarios persist in the configured JSON data file across service restarts.

Response behavior

Registered transaction
HTTP 200 with transaction status Failed and the configured ACH return details.
Unregistered transaction
HTTP 200 with transaction status Success.
Registration and management
POST /api/transactions, GET /api/transactions, and DELETE endpoints.

Internal QA use only. This mock does not validate SnapPay credentials or HMAC signatures and must not be exposed publicly.
